# ستار بيوتي — مخطط المشغل التفاعلي

مخطط توزيع تفاعلي لمشغل تزين نسائي متكامل على ست فتحات تجارية مدموجة، بطابقين.

## المحتوى

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة التفاعلية — المخطط قابل للضغط والتكبير |
| `files/Star-Beauty-Salon-R06.dxf` | ملف الأوتوكاد (DXF R12، وحدة المليمتر) |
| `files/Star-Beauty-Areas-R06.csv` | جدول المساحات والسعات وإحداثيات كل غرفة |
| `files/Star-Beauty-Salon-R06-preview.svg` | معاينة كاملة للورقة بما فيها الجداول والملاحظات |

## المقاسات

| البند | القيمة |
|---|---|
| عدد الفتحات | 6 |
| العرض الصافي | 29.80 م |
| العمق | 17.70 م |
| الارتفاع الكلي | 6.50 م |
| مساحة الطابق الأرضي | 527.46 م² |
| مساحة الميزانين | 432.10 م² |
| **الإجمالي** | **959.56 م²** |
| محطات وكابينات | 75 |

## مصدر واحد للبيانات

كل رقم في الصفحة مقيس آلياً من مضلع الغرفة في ملف الأوتوكاد. المخطط التفاعلي نفسه مستخرج من الـDXF بسكربت، ولم يُعَد رسمه يدوياً. مجموع مساحات الغرف يساوي مساحة القشرة بالضبط:

```
527.46 + 432.10 = 959.56 م²
```

## التشغيل محلياً

الصفحة ملف واحد قائم بذاته بلا أي اعتماديات خارجية. يكفي فتح `index.html` في المتصفح.

## حالة المشروع

مسودة عمل. عرض الفتحة 4800 مم والعمق 17700 مم مشتقان من قياس تقريبي بالموقع، ويبقيان رهن المخطط المساحي المعتمد. مواقع الأعمدة الإنشائية غير مثبتة بعد.
